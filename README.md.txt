# OWASP Juice Shop Security Assessment

## Project Title
Security Assessment of OWASP Juice Shop using OWASP ZAP

## Objective
Deploy the OWASP Juice Shop application in Docker and perform a basic web application security assessment using OWASP ZAP.

## Tools Used
- Kali Linux
- Docker
- OWASP Juice Shop
- OWASP ZAP 2.17.0
- Mozilla Firefox

## Project Workflow
1. Install and start Docker.
2. Run OWASP Juice Shop in a Docker container.
3. Open the application at http://localhost:3000.
4. Launch OWASP ZAP.
5. Explore the application through ZAP.
6. Capture HTTP requests and responses.
7. Review alerts and document findings.

## Expected Outcome
- Successfully deploy OWASP Juice Shop.
- Capture web traffic using OWASP ZAP.
- Perform basic security analysis.
- Generate a security assessment report.

## Conclusion
The project demonstrates the fundamentals of web application security testing using OWASP Juice Shop and OWASP ZAP in a controlled environment.
